# On the Landscape of Spoken Language Models — Interspeech 2026 Tutorial

Website: https://interspeech2026slm.github.io/

Sunday, 27 September 2026 · Morning session · International Convention Centre Sydney

The tutorial is based on our survey:
**On The Landscape of Spoken Language Models: A Comprehensive Survey** (TMLR 2025) — [arXiv:2504.08528](https://arxiv.org/abs/2504.08528)

## Editing the site

The whole site is `index.html` (styles included) plus images in `assets/`.
Speaker photos are 320×320 JPEGs in `assets/people/`; add a new speaker by copying one `<div class="person">` block.
Pushing to `main` publishes the site through GitHub Pages.
